## Analysis Scripts
* **homo.py** - Scripts that generate the initial trajectory. No ion exists in this system.
* **InternalEE.py** - Scripts calculating the internal ene-to-end distance. The output is restored in the file "tmp.data"
* **PPPM.py** -Scripts calculating the density, average bond length, end to end distance, standard deviation of angle and average angle.
* **fittingkappa_kappaadmodel** - Matlab script for the calculation of n_k at different angle (Each five column is corresponding to a case with a certain angle, each row is corresponding to a certain step). 
* **tgfita.m** - Matlab script to fitting the Tg using density-temperature curve.
